# Titan

Personal multi-AI chat app (Capacitor + Ionic + React). BYOK — talk to Claude, GPT, or Gemini per project, with per-project memory. No backend, no auto-routing, no vector DB in v0.1.

**Before doing any work here, read `docs/AI_HANDOFF.md`** — it points to the full context (`docs/PROJECT_CONTEXT.md`), architecture (`docs/ARCHITECTURE.md`), roadmap (`docs/ROADMAP.md`), and the decision log (`docs/DECISIONS.md`) that explains *why* things are the way they are. Don't re-decide something already logged in `docs/DECISIONS.md` without flagging it explicitly.

Git workflow: `main` / `develop` / `feature/*` (`bugfix/*`). Work happens on a branch off `develop`, merged via PR.
